# sum-of-squares-for-control-overview-part-I-analysis
Проект содержит исходный код для научной статьи "SOS-Программирование для анализа и синтеза систем управления.Ч. I: анализ устойчивости"

Для его запуска потребуется Matlab и следующие дополнительные пакеты:
1) Yalmip (https://yalmip.github.io/)
2) SOSTOOLS (https://www.mit.edu/~parrilo/sostools/)
3) SeDuMi (https://sedumi.ie.lehigh.edu/?page_id=58)
4) Mosek (https://www.mosek.com/)

Инструкции по установке могут быть найдены в соответствующих пакетах программ.

Для Mosek существует академическая лицензия (https://www.mosek.com/products/academic-licenses/), которая выдается на один год. Если вы не хотите ее получать, то можете заменить в исходном коде данного проекта mosek на sedumi, однако при этом вы получите результат, который будет отличаться от приведенного в статье.

**Описание проекта**
1) Приложение 3.1 - пример 3 из статьи, поиск функции Ляпунова для осциллятора Ван дер Поля с обратным временем.
2) Приложение 3.2 - пример 3 из статьи, поиск наибольшей линии уровня полученной функции Ляпунова, которая целиком содержится в множестве G.
3) Приложение 3.3 - пример 3 из статьи, визуализация полученного результата.
4) Приложение 3.4 - пример 4 из статьи, поиск функции Ляпунова для системы из примера 4.
5) Приложение 3.5 - пример 4 из статьи, визуализация полученного результата.
6) Приложение 3.6 - пример с маятником из раздела 3.6 статьи, поиск функции Ляпунова.
7) Приложение 3.7 - пример 5 из статьи, поиск функции Ляпунова для системы с параметрической неопределенностью из примера 5.
8) Приложение 3.8 - пример 5 из статьи, визуализация полученного результата.
9) Приложение 3.9 - пример 6 из статьи, аппроксимация множества достижимости линейной системы (с визуализацией).
